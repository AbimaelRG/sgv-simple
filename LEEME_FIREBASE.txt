CONEXION CON FIREBASE (proyecto sgv-ver-1) - 5 pasos

Ya quedaron puestos: la configuracion web (static/firebase-config.js) y el archivo .env.
Falta lo que solo puedes hacer tu en la consola de Firebase:

1) Activar los servicios  (https://console.firebase.google.com/project/sgv-ver-1)
   - Build > Authentication > Comenzar > Metodo de acceso > "Correo electronico/contrasena" > Habilitar.
   - Build > Firestore Database > Crear base de datos > modo PRODUCCION > region us-central1 (o la mas cercana).
   - Build > Storage > Comenzar > modo PRODUCCION. (El bucket debe llamarse sgv-ver-1.firebasestorage.app.
     Si Storage pide el plan Blaze, puedes dejar Storage para despues: todo lo demas funciona sin el;
     solo la carga de evidencias avisara que no esta disponible.)

2) Descargar la clave del servidor
   - Configuracion del proyecto (engrane) > Cuentas de servicio > "Generar nueva clave privada".
   - Guarda el archivo .json en esta carpeta con el nombre exacto:  clave-firebase.json
   - Es SECRETA: no la subas a Git, no la mandes por chat ni correo.

3) Instalar y crear el administrador
   python -m venv .venv
   .venv\Scripts\activate          (Mac/Linux: source .venv/bin/activate)
   pip install -r requirements.txt
   python crear_admin.py           (te pide nombre, correo y contrasena)

4) Arrancar
   python app.py
   Abre http://127.0.0.1:5000 e inicia sesion con el correo y contrasena del paso 3.

5) Comprobar
   Registra un activo y una vulnerabilidad: deben aparecer en Firebase > Firestore Database > Datos
   (activos, vulnerabilidades, seguimientos, auditoria).
   Desde "Usuarios y permisos" crea al resto de usuarios (tecnico, auditor, etc.).

Si algo falla: copia el mensaje de error completo de la terminal y mandamelo.
